# ADR-0006: 전환율은 "신청 수 / 순 방문자 수"로 정의한다

## 상태
Accepted

## 맥락
요구사항은 "캠페인별 방문, 방문자, 신청, 전환율을 확인할 수 있어야 합니다"라고 하지만
전환율의 분모를 "방문 수"로 할지 "방문자 수"로 할지는 명시하지 않았다.

## 결정
전환율 = 신청(Submission) 수 / 순 방문자(DISTINCT visitor_token) 수로 계산한다.

## 근거
- "방문 수"를 분모로 하면 같은 사람이 여러 번 새로고침/재방문할수록 전환율이 낮아져
  실제 폼의 설득력을 왜곡할 수 있다.
- "방문자 수" 기준이 마케팅 지표로서 더 일반적으로 쓰이는 정의다.

## 결과
- 장점: 재방문에 의한 전환율 왜곡이 적다.
- 단점: 한 방문자가 같은 캠페인에 여러 번 신청하는 경우(중복 신청)를 어떻게 셀지는 별도
  결정이 필요하다 — 이번 스코프에서는 신청 자체를 막지 않고 Submission을 건수 그대로
  누적하므로, 신청 수가 방문자 수를 초과해 전환율이 100%를 넘는 경우가 이론상 가능하다.
  중복 신청 방지는 과제 범위 밖으로 판단해 구현하지 않는다.
