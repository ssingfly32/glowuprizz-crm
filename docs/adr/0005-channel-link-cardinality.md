# ADR-0005: 캠페인당 채널별 배포 링크 개수를 제한하지 않는다

## 상태
Accepted

## 맥락
요구사항은 "운영자는 인스타그램, X, 유튜브, 스레드용 배포 링크를 만들 수 있어야 합니다"라고만
되어 있고, 채널당 링크 개수 제약은 명시되지 않았다.

## 결정
(campaignId, channel) 조합에 유니크 제약을 두지 않는다. 배포 링크 생성 API는 create-only이며,
같은 채널로 여러 번 호출해도 매번 새 링크가 생성된다.

## 근거
- 1개로 제한하는 안은 유니크 제약 + "이미 있으면 재발급(토큰 갱신)"이라는 update 흐름이
  추가로 필요해 코드가 더 복잡해진다.
- 무제한 허용은 create API 하나로 끝나고, 성과 집계는 어차피 channel 컬럼 기준 GROUP BY이므로
  링크 개수와 무관하게 쿼리가 동일하다.
- 실제 운영 시나리오(인스타 바이오 링크 vs 스토리 링크)에도 여러 개 허용이 더 자연스럽다.
- 데모/구현 범위에서는 캠페인당 채널당 1개씩만 생성해서 흐름을 검증한다. "여러 개 허용"은
  시스템이 막지 않는다는 것이지, 여러 개를 만드는 기능을 별도로 구현한다는 뜻이 아니다.

## 결과
- 장점: 구현이 단순하고 확장에 유연하다.
- 단점: 채널당 링크가 여러 개일 때 "대표 링크"를 구분할 라벨 필드가 없다. 필요해지면
  DistributionLink에 nullable label 컬럼을 추가하면 된다 (현재 스코프에서는 생략).
